# リハ・アシスト（リハビリ音声ガイドWebアプリ）

リハビリ対象者（シニア・療養中・ベッドサイド）に向けた、音声主導の自立支援・リハビリ練習用Webアプリケーションです。
画面を見続けなくても、耳からの音声案内だけで無理なく安全に運動を行えます。

## 主な機能
1. **本日のリハビリコース（おまかせ連続再生）**
   - 「通しでスタート」を1回タップするだけで、呼吸 ➔ 腕 ➔ 足 を適切な休憩を挟んで自動進行します。
2. **個別メニュー選択**
   - **呼吸・息溜め練習**（約8分）: 肺を心地よく広げるブレススタッキング（エアスタッキング）。
   - **腕と肩のリハビリ**（約3分半）: 肩の上げ下げ、肘の曲げ伸ばし、手首・指の体操。
   - **足のリハビリ**（約3分半）: 足首の曲げ伸ばし、かかと・つま先上げ、膝・太もものやさしい運動。
3. **視覚・タイマー同期機能**
   - 画面を見られる方向けに、「吸う・キープ・吐く・休憩」の動作と残り秒数を大きなサークルで視覚表示。
4. **安全設計**
   - 大きな停止・再開ボタン、無理をさせない音声声掛け、誤操作を防ぐレイアウト。

## 起動方法

### 方法1: バッチファイルをダブルクリック
フォルダ内の `アプリ起動.bat` をダブルクリックするだけでブラウザが起動します。

### 方法2: Pythonから起動
```bash
python scripts/start_server.py
```
起動後、ブラウザで `http://localhost:8080/index.html` にアクセスしてください。

## 音声の再生成・追加
SSMLを編集または追加した場合、以下のスクリプトでMP3とタイムラインを再生成できます。
```bash
python scripts/generate_audio.py
```
