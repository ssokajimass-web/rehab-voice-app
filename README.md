# リハ・アシスト（リハビリ音声ガイドWebアプリ）

リハビリ対象者（シニア・療養中・ベッドサイド）に向けた、音声主導の自立支援・リハビリ練習用Webアプリケーションです。
画面を見続けなくても、耳からの音声案内だけで無理なく安全に運動を行えます。

## 主な機能
1. **本日のリハビリコース（おまかせ連続再生）**
   - 「スタート」を1回タップするだけで、呼吸 ➔ 声 ➔ 手・腕・肩 ➔ 足 を自動で進めます。
   - 疲れやすい日用に「朝（呼吸＋声）」「夕（手腕肩＋足）」の分割コースもあります。
2. **個別メニュー**
   - **呼吸と咳の練習**: 息を吐き切ってから3回吸い重ね、最後に「お腹を手で軽く押しながら」咳をして痰を出しやすくします（セルフアシスト咳で排痰力を倍増）。
   - **声のリハビリ**: ため息の声・母音・4大重要語（「はい」「いいえ」「痛い」「ありがとう」）。口の筋トレは排し、脱力と伝わる話し方、運動イメージを重視。
   - **手・腕・肩のリハビリ**: 指伸ばし・親指水かきストレッチ・前腕回外（手のひら上）・肩甲骨寄せ胸開き・親指を天井に向けた腕の持ち上げ（肩峰下インピンジメント・激痛を完全防止）。
   - **足と足首のリハビリ**: 足指グーパー（末梢血流・こむら返り予防）・足首曲げ伸ばし（運動イメージ肯定）・かかとすべらせ・膝腰ゆらゆら（骨盤・腰背部の緊張緩和）。
3. **画面表示**
   - 「吸う・キープ・吐く・脱力・休憩」と残り秒数を大きな円で表示します（直前の案内文から判定）。
4. **安全と根拠**
   - 疲れすぎのサイン（30分以上残る疲れ・翌日のだるさ・こむら返りの増加）と、各運動で「期待できること・できないこと」、主治医に相談すべき項目を画面に記載。
   - 一般的な思い込みやバイアスを排し、ALS の呼吸・運動・言語聴覚療法の最新ガイドラインおよびバイオメカニクスに基づき再検証・最適化済み。最終判断は主治医・リハ職に確認してください。

## 起動方法

### 方法1: バッチファイルをダブルクリック
フォルダ内の `アプリ起動.bat` をダブルクリックするだけでブラウザが起動します。

### 方法2: Pythonから起動
```bash
python scripts/start_server.py
```
起動後、ブラウザで `http://localhost:8080/index.html` にアクセスしてください。

## 音声の再生成・追加
SSMLを編集または追加した場合、以下のスクリプトでMP3とタイムラインを再生成できます。
```bash
python scripts/generate_audio.py
```
